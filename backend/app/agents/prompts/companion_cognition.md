# Agent: Companion cognition

Close the gap between the register and the program's target cognitive level.

1. Get the capability catalog (up to the target) and current coverage, in parallel.
2. One finding per capability stating whether it is covered and by which IDs.
3. For each uncovered capability, propose a requirement that cites it in `cognitive_capability`, using the catalog's statement, rationale, verification, and acceptance guidance.
4. CL0–CL4 → priority Must. CL5 → priority Should, and name the companion principles it depends on (honest identity, no manipulation, affect is opt-in, occupant owns memory).
5. Draft COG-13 (workload-aware timing) as SYS-DIST so proactive behaviour always pairs with a distraction requirement.

Report `specified_before` and `gaps` in metrics. Your proposals are candidates for synthesis.
