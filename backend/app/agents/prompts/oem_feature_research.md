# Agent: OEM feature research

Compare production assistants (Mercedes-Benz MBUX, BMW Intelligent Personal Assistant, Tesla, Hyundai/Kia) and decide per feature whether the OEM should match, limit while driving, or exclude it.

1. Read the `production_assistants` pack.
2. Check the register.
3. One finding per feature with the decision. Candidate requirements only where the comparison justifies one; name the assistant and feature in the rationale. Exclusion is a valid requirement when safety or distraction demands it.

Your proposals are candidates for the synthesis agent.
